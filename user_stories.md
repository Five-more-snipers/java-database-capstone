**Title:**
_As a Admin, I want Master Data Management, so that Admin can ensure the operation an be onverseen in scalable manner, faster action time to correct any perceived mistakes, and adapt when unforeseen circumstances appear._

**Acceptance Criteria:**
1. Admin can Log into the portal with your username and password to manage the platform securely.
2. Admin can Log out of the portal to protect system access.
3. Admin can Add doctors to the portal.
4. Admin can Delete doctor's profile from the portal.
5. Admin can Run a stored procedure in MySQL CLI to get the number of appointments per month and track usage statistics.


**Priority:** Medium
**Story Points:** 50
**Notes:**
- The execution of any action can only be allowed with active admin account.
- When creating the app, it is mandatory to have atleast 1 active Admin account. Admins can create and delete additional admin accounts but must reject eh action if the end results is no admin account.

**Title:**
_As a Patient, I want Comprehensive Hospital Arrangement Management System, so that Patient can ensure seamless appoinment with minimal hassle._

**Acceptance Criteria:**
1. Patient can View a list of doctors without logging in to explore options before registering
2. Patient can Sign up using your email and password to book appointments
3. Patient can Log into the portal to manage your bookings
4. Patient can Log out of the portal to secure your account
5. Patient can Log in and book an hour-long appointment to consult with a doctor
6. Patient can View my upcoming appointments so that I can prepare accordingly

**Priority:** High
**Story Points:** 30
**Notes:**
- When register their account, patient must run the email verification system where they access the email to find the verification message and proceed there to activate the account.

**Title:**
_As a Doctor, I want Secure and easy Appoinment management system, so that Doctor can arrange the appoinment easily and with flexibility._

**Acceptance Criteria:**
1. Doctor can Log into the portal to manage your appointments
2. Doctor can Log out of the portal to protect my data
3. Doctor can View my appointment calendar to stay organized
4. Doctor can Mark your unavailability to inform patients only the available slots
5. Doctor can Update your profile with specialization and contact information so that patients have up-to-date information
6. Doctor can View the patient details for upcoming appointments so that I can be prepared

**Priority:** Low
**Story Points:** 20
**Notes:**
- When doctors are creating their account, they must have permission or confirmation form admin directly.
